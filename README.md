# Pokemon App

แอปพลิเคชัน React Native (Expo) สำหรับแสดงข้อมูลโปเกมอน

## ฟีเจอร์

- แสดงรายชื่อโปเกมอน
- ดูรายละเอียดของโปเกมอนแต่ละตัว
- ออกแบบUIที่สวยงามและใช้งานง่าย

## การติดตั้ง

```bash
# ติดตั้ง dependencies
npm install

# รันแอปพลิเคชัน
npx expo start
```

## เทคโนโลยีที่ใช้

- React Native
- Expo
- TypeScript

## การใช้งาน

1. รันคำสั่ง `npm install` เพื่อติดตั้ง dependencies
2. รันคำสั่ง `npx expo start` เพื่อเริ่มต้นแอปพลิเคชัน
3. ใช้งานได้ทั้งบน Android, iOS และเว็บเบราว์เซอร์
